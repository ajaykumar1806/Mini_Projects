# Mini Projects Repository

## Overview
This repository contains a collection of **mini projects** developed to strengthen core programming concepts in **C and C++**.  
Each project is written in a **simple, student-friendly style** and focuses on fundamentals such as file handling, data structures, and object-oriented programming.

---

## Projects Included

### 1. Custom UNIX Command Utilities in C Using File Concepts
Implementation of basic UNIX commands using **C standard file handling (FILE*)**, without using system calls.

**Utilities:**
- `cp`   – Copy files using `fopen`, `fread`, `fwrite`
- `grep` – Search a word in a file line by line
- `wc`   – Count lines, words, and characters
- `getline` – Custom implementation of `getline()`

**Concepts Used:**
- File I/O (`fopen`, `fclose`, `fread`, `fwrite`, `fgets`)
- Strings and buffers
- Command-line arguments

---

### 2. Student Database System Using C and Linked List
A menu-driven application to manage student records using a **singly linked list**.

**Features:**
- Add student record
- Display all records
- Search by roll number/name
- Delete a record
- Update student details

**Concepts Used:**
- Structures
- Dynamic memory allocation
- Linked list operations
- Modular programming

---

### 3. Custom String Class (C++)
A beginner-level implementation of a custom string class to understand **OOP concepts** in C++.

**Features:**
- Constructors and destructor
- String length calculation
- Copy and compare strings
- Concatenation operation
- Operator overloading (basic)

**Concepts Used:**
- Classes and objects
- Constructors / destructors
- Dynamic memory management
- Encapsulation
